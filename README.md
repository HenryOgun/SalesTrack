# SalesTrack — Business Sales Tracker

A Progressive Web App (PWA) for small business daily sales tracking, packaged as an Android APK and signed AAB for the Google Play Store.

🔗 **Live Demo:** [henryogun.github.io/SalesTrack](https://henryogun.github.io/SalesTrack/)

---

## Features

- **Offline-first** — works without internet via service workers
- **Sales logging** — record daily sales quickly on mobile
- **Daily summaries** — view totals and history at a glance
- **Mobile-optimised UI** — designed for small screens
- **Installable** — add to home screen on Android and iOS
- **Google Play ready** — signed AAB built with Bubblewrap (TWA)

---

## Tech Stack

- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **PWA:** Service Workers, Web App Manifest
- **Android Packaging:** Bubblewrap (Trusted Web Activity / TWA)
- **Signing:** Android Keystore (release-signed AAB)
- **Deployment:** GitHub Pages

---

## Installation

**As a web app:**
Visit [henryogun.github.io/SalesTrack](https://henryogun.github.io/SalesTrack/) and tap "Add to Home Screen" on mobile.

**As an Android APK:**
Download from Google Play or install the APK directly.
